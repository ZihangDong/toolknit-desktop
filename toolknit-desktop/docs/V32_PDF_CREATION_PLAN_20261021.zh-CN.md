## 图像转 PDF

### 输入与页面

- 拟支持 JPEG/PNG/BMP/WebP/GIF/TIFF；GIF/动态 WebP 取首帧，TIFF 多页展开，界面给出正确页数。
- 文件扩展名与真实解码分别检查；损坏、不支持或超预算的条目展示失败原因，用户移除后继续，不悄悄漏页。
- 首批按文件名自然顺序排列，中文、数字、重名有稳定次序；手工排序后继续添加只追加，不打乱已有顺序。
- 每页持有独立 ID、原始来源、旋转与预览状态。同名、重复选入、TIFF 多页、删除后重加不共享错误状态。
- 默认 A4、自动方向、等比居中和适当留白；原图尺寸使用可靠 DPI 或统一缺省映射。输出显示实际纸张尺寸，避免像素与印刷单位混用。
- 不自动裁切长图、证件边缘或模糊小图。原图 DPI 与目标采样分开，高 DPI 不等于恢复细节。

### 效果与交互

- 原图彩色默认，灰度和自然扫描可选；自然模式复用现有噪点、暖色及轻微倾斜，保留完整内容。
- 左参数、中预览、右缩略图；多选/拖入、继续添加、拖动排序、删除、90 度旋转、缩放、重置和唯一名称保存。
- 清晰/均衡/体积优先三档；文本截图优先保留锐利边缘，原图直嵌仅在无需像素修改且安全时使用。
- 可取消真实进度和统一成功弹框，打开文件夹选中本次结果。关闭、重开、切换工具、语言/主题变化隔离旧结果。

### 容量与实现

- 初始预算：最多 100 页，输出 100 MiB；输入/解码像素/总内存限额在首轮矩阵中确定并统一声明。
- 缩略图和原图分离，逐页解码与释放，后台像素处理/编码；避免一次保存所有完整 RGBA 缓冲。
- 独立 `features/image-to-pdf/`；公共扫描算法、写出与布局抽到 shared/core，旧 feature 保留兼容转发，禁止 feature 直接互相 import。
- Native 图片规范化走现有图像域和平台 adapter；当前 image crate 未启用 TIFF，需明确依赖许可、解码限制、多页支持和锁文件增量。
- PDF 写入优先复用既有分块临时写入、qpdf 检查与唯一名称发布，不添加另一套输出根目录规则。

## PDF 编辑器

### 无文件创建

- 空状态新增“新建空白 PDF”；侧栏空白页操作在无文件时也可创建第一张 A4。
- 创建有效 PDF 字节并走文件会话的暂存、加载、提交、预览、基线与历史初始化，而非只插入一张 DOM 空纸。
- 新建文档属于未保存内容；导出前关闭/替换需要现有丢弃提示，导出后仅实际保存状态更新。
- 已有文档插入空白页保持当前页可见宽高，含横页和旋转页，默认第一页为 A4。
- 创建、重复点击、加载失败、取消、销毁和新旧会话交错必须有测试。取消或失败不能毁掉原文档。

### 本轮深度优化范围

- 空白页插入中英文字、图片、矩形/椭圆/线条，选中移动缩放旋转与删除。
- 页复制/删除/排序/旋转后，文本、图像和形状始终属于正确页面；插入图像在撤销重做后仍可见可导出。
- 撤销/重做/重置的 saved/baseline 区分；空白文档不退入不可恢复的“无来源”状态。
- 追加真实 PDF、混合纸幅及旋转页、提取页面、重复导出，输出页序与预览一致。
- 编辑中文长文本、不同字号、比例锁定、缩放后的指针命中与文本框边界，按已复现问题修补。
- 大文档只加载可见页，取消渲染/Worker/Object URL、失败后重试、退出重开和内存回收。
- 首屏、工具栏、弹框、页面列表在深浅主题/中英文/低高度布局下可操作；导航复用既有 shared shell。
