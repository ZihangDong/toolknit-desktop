# V3.3 正式发布

2026-11-15。用户授权桌面版与 npm CLI/MCP 3.3.0 一起发布，并允许以仓库管理员权限合并 main。

## 范围与验证

- 作者代码、PDF 转 Word 引擎和 CLI/MCP 采用 MIT；推荐来源链接不构成强制条款。第三方许可与旧版记录保留。
- 双语 README、帮助、changelog 与正式发布说明切换至 V3.3。目录为 75 工具、12 分类、78 项 CLI/MCP 能力。
- 完整发布门禁 116 项 npm 脚本通过，含架构、安全、独立 CLI 安装、真实 Office/PDF 输出与官方 MCP SDK。受影响的版本、帮助和 MIT 契约通过。
- GitHub Windows runner 的 TMP 含 8.3 短路径别名时，Vite 规范化后的根路径与夹具不一致。测试改用 realpath 后再创建临时目录，保留真实 watcher 订阅断言；focused 与架构检查通过。仅测试兼容修正，不改变应用或 npm 运行代码。
- 发布后继续修复 CI 的字体环境差异：写字线夹具改用固定许可字体；会注册合成字体别名的两个夹具隔离在子进程，避免 ESM 顶层异步执行期间共享或移除其他测试的全局字体。保持像素、字体、规则归属及内容不变断言，不把合成别名当作真实仿宋验收。通用夹具覆盖固定字体及 runner 常备 CJK 字体；依赖真实仿宋轮廓的小零与混合字体反例仅在该字体存在时执行，缺失明确报告，不能用替代字体冒充；字体组改变修复路径时，保留完整输出断言，仅对实际执行的重试检查预算上界。此项仅更新测试与记录，已发布标签及运行产物保持原始身份。
- 沿用本轮功能基线的完整 Rust 338 passed / 31 ignored、真实 WebView2 浮窗及 PNG/SVG/分页验收、隔离安装器 20 项和升级 21 项证据。本次正式文案更新未改变 Rust 功能。
- 最终安装包由生产配置重新构建，关闭 DevTools/F12，不启用 qa-devtools。安装器、载荷、npm 归档与 Git 源码树分别记录校验信息；测试包不改名代替正式包。

## 交付与边界

GitHub v3.3.0 包含安装包、单文件 SHA-256、干净源码及来源清单。源码仅从实际 main 合并提交归档并逐 Git blob 验证；不包含私有 Skill、用户样本和本地缓存。npm 发布同一已独立安装验证的归档，并核对官方 registry latest/integrity。

官网双语桌面页同步 V3.3、MIT、OCR、文件搜索与下载链接；保留网页端独立版本、统计、模型缓存与数据。远程验收与最终哈希存放于交付目录及私有部署回执。

已知限制：安装包未做 Authenticode 签名；干净实体设备、混合 DPI 尚未在本轮重新实测。复杂扫描/公式仍需人工校对。MTran/Bergamot、Mozilla 模型通知及 LibreOffice 通知材料沿用分发报告的待办，不能宣称全部闭环。既有大 chunk、crypto externalization、Windows linker 和上游 unmaintained 提示保留。

正式产物与服务端 readback 验证结果以仓库外发布清单为准，不在本文复制私密运维信息。
