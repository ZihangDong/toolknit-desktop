# Repository visual assets

Place repository-facing visual assets in this directory.

- `readme-hero.gif`: the full-width animated opening image shown at the top of the root README.
- `donate-wechat.png` / `donate-alipay.png`: optional official donation QR images when their corresponding channels are published in `docs/SUPPORT.md`.

Use optimized assets. Do not add source videos, raw design files, user screenshots containing private data, or files that are unnecessarily large for a GitHub README.
