## 范围与方法

本轮覆盖十类 AI 入口：润色、翻译、PDF 视觉 Markdown、PDF 转 Word 辅助排版、PPT 文本整理、大纲、草稿、AI 文档、AI 表格、离线转写后的 AI 润色。中英双向翻译和 PPT 四种整理模式分别测试，并验证取消后 MCP 仍可继续调用，共十五个场景。

- 通过实际 CLI JSON/标准输入入口与官方 MCP SDK stdio 客户端调用，使用用户指定模型，没有换成其他模型。
- 输入为专门生成的中英文文本、一页 PDF、三页 PPTX 和系统合成语音。未上传用户历史文件、剪贴板内容或私人 PDF。
- 校验事实、数字、姓名、Word 可编辑文字、PDF 页数、PPTX/XLSX 包结构、工程修改与撤销、字幕编号和时间码、原件哈希。
- AI 文档生成后实际执行 inspect、修改标题、undo、render；表格生成后实际修改单元格、undo、render。检查中文文档两页预览与表格图表预览，未见遮挡或空白。
- 远端付费测试是 `npm run test:cli-ai-live -- --live`，不会随普通测试自动运行。凭据只在必要测试进程环境中传递，不进入源码、命令参数、证据文件或 npm 归档。

### 官方 SDK 进度回调

SDK 1.32.1 将通知处理放入微任务，但最终结果处理同步移除回调。当 100% 通知和结果出现在同一 stdio 数据批次时，客户端可能漏掉末次 `onprogress`。服务端发送顺序正确，任务结果及输出文件正常。本轮验收直接检查实际接收线序、0 到 100 的单调进度和最终响应顺序，保留官方 SDK 调用与取消验证，不给服务端添加人为延迟。此处是客户端回调限制，不是模型请求失败；客户端应以最终工具结果为完成依据。

## 边界

本轮是 Windows 本机、合成小样本及真实中转站验证，不代表其他平台、任意长文件或中转站所有时段的速度保证。Office 与离线转写仍需要已有外部运行时/模型，测试不会自动下载。

已知 Vite 大 chunk/crypto externalization、Windows linker 信息，以及部分 ExcelJS 上游 deprecated 提示保留。未改桌面 UI，未重新构建桌面 EXE 或声称新安装 GUI 回归通过；未提交 Git、推送 GitHub、发布 npm 或创建 Release。
