# V3.3 无 AI 扫描转换优化合入

2026-11-13，当前 V3.3 开发工程。用户授权将独立项目已验收成果合回桌面并重新测试。

## 来源和范围

独立项目实现检查点 `49d2f25`，后续 `09a6ff7` 仅交接文档。本次不是把整个独立仓库或其界面、依赖安装和临时文件合入；按共同基线核对后，移入四处原引擎改动和三份新增算法。

- `core/scan-figure-regions.js`：有界扫描非文字墨迹分区，保持正文/表格隔离、完整图内标注，未知混合页继续原路径。
- `adapters/scan-figure-assets.js`：从未擦字的可见页裁完整 PNG，保持原像素及图层位置。
- `core/ocr-scene.js`：图内文字归图像，背景对应区域挖空，保持唯一来源，避免删图后残留第二层图形。
- `adapters/scan-text-typography.js`：根据源像素和邻行物理字号精修普通扫描文字；保护真实粗体，修复选项句点异常黑点，不改 OCR 原文。
- `adapters/ocr-fonts.js`：已验证样式文字不再重复生成像素轮廓字体，减少锯齿。
- `processor.js`、`worker.js`：复用逐页转换、OCR、资产与字体生命周期。
- `controller.js`：桌面转换显式启用两项策略，维持纯转换、选页、结果弹框和结构化编辑交接。

四个既有文件合入前与独立项目保存的共同基线逐字节一致。新增文件仅补齐桌面统一许可头；算法逻辑保持已验收实现，不带入旧私有试验。

## 契约和边界

processor 可选项 `preserveScanFigures`、`refineScanText` 默认 false，只有桌面转换入口开启。旧调用者、CLI/MCP、截图OCR、模型下载及 Rust 实现不变。Worker 使用既有 OCR 消息携带布尔策略；WordScene 版本不变，新增图形是原图像类型的来源元数据。

不增加AI、模型或依赖，不修改用户设置、密钥、历史和原文件。仍使用现有 PP-OCRv5、本地原生适配与共享 Word 文档编辑器。源文件只读，输出唯一发布。

## 已知限制

主要对完整扫描页生效，不宣称对所有原生/混合页完成通用语义分区。图内文字作为图像保留，不计可编辑文字。少量特殊字/极短行仍有字体回退；几何定位输出不是自然流式段落。历史20份239页严格整篇14/20不因本次合入变更，不填写新的通用准确率。

本轮不接入 AI，不自动延续旧的全面优化目标。按具体文件反馈继续维护。
