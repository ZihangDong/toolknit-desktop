# V3.3 文件快速搜索实施记录

日期：2026-11-04。NTFS 大小写改名增强用例、C/D 盘直接增量、退出后补齐及回收通过，临时服务已卸载。用户确认单屏功能正常，圆角边缘、空状态 Logo 和动画优化后再次确认“没啥问题了”。功能开发及本机验收已闭合，可进入测试包阶段；实体多屏和其他硬件兼容性仍待补测。产品依据为 [完整规划](V33_FILE_SEARCH_PRODUCT_PLAN_20261103.zh-CN.md)，来源与许可依据为 [Win顺审查](V33_WINSHUN_REUSE_AUDIT_20261103.zh-CN.md)。

## 已实现范围

- 独立工具页 + 白底黑字胶囊；共用索引、独立查询。中文、拼音、空格多条件、后缀筛选、自然名称/大小/时间排序，分页和有限 DOM。
- 每行仅「打开所在位置」，使用 Shell PIDL 定位，不执行文件。原生验证查询租约、结果 ID、原路径和搜索范围，过期或另一入口的结果不能复用。
- 配对窗口保留 20 个逻辑像素的真实间距，圆角使用原生命中区域；胶囊变形同步原生裁剪，阴影不拦截鼠标。预热独立圆角菜单，支持工具页交接、临时隐藏和停用。
- 圆角原生裁切为 CSS 半透明边缘保留 2 个物理像素余量，窗口尺寸及透明间隙不变。空状态复用记录模式的 `/logo.png`，状态轮询不重建同一空状态；胶囊变形统一 320ms 缓出，结果表面仅淡入/淡出，内部内容轻微位移；支持减少动态效果，隐藏时移出焦点并设 inert。
- 创建失败或输入/结果 HWND 异常销毁时，失效旧动画并收回整组窗口，保留已启用偏好；工具页开关可立即重试。此项覆盖窗口销毁，不等同于全部 WebView2 渲染进程崩溃场景。
- 拖动松手约 200ms 缓出回到工作区，适配负坐标、DPI、上方展开；检测工作区变化并修正位置。截图隐藏恢复遵守最新显示意图。
- 本机目录缓存、变化监听、漏事件修复、退出后补齐、范围替换和清除重建。仅修改名称大小写时按改名事件撤销旧条目，不依赖存在检查。
- 完全退出停止索引，托盘运行继续。搜索词只保留进程会话，不写入缓存。索引不读取正文；清除索引不删除源文件。
- 可选按需 NTFS 服务、只读 MFT/USN、用户 SID/管道身份绑定、目录 ACL 检查、断连/父进程退出回收。本机缓存目录限制当前用户、SYSTEM 和管理员访问；真实管道测试验证识别级 token 与账户隔离。安装源与复制后的主机哈希校验，升级可更新服务主机；完整卸载只清理归属于当前安装路径的生成服务，避免误删其他用户或其他安装位置的加速器；覆盖升级保留按需服务。

## 当前限制

已接入用户主动选择的 UNC 和映射网络盘，通过普通权限独立进程隔离网络 I/O。单次无响应 8 秒超时，单轮扫描上限 10 分钟；共享目录约每 30 秒重新校正，缓存仍在本机。超时/取消不会将部分扫描当作完整结果而删除旧索引。已验证本机既有共享入口，异机 NAS 和 WAN 断网组合仍未逐一实测。缓存异常明确提示先清除索引再重建；原文件不变。多音字能力取决于上游词典，不等于语义搜索。

工具页跟随深浅主题；胶囊按用户要求固定白色。默认不开启胶囊，也不自动扫描所有磁盘。加速服务需要用户主动选择并通过 Windows 管理员确认；不可用时普通目录模式继续工作。
