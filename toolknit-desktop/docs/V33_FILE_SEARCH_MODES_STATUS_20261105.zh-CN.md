# 文件搜索双入口与状态稳定性修复

日期：2026-11-05。V3.3 未发布，本轮仅本地修改和验证。

## 根因

- 两入口原本分别查询、共享索引，但页面未限制同时活跃。胶囊已启用时主窗口仍保留可查询工作台。
- results.setIndex 把全局 generation 改变当成当前查询改变，直接重查或显示“有更新”；无关文件变更也会触发“正在查找 / 找到 N 个”切换。
- 普通目录复核发布 indexing，远程复核每轮先标旧条目未核实、再恢复。文件未变也会制造版本变化，目录事件的短扫描反复切换就绪文字。

## 实现

- 按已保存的胶囊 enabled 控制互斥；折叠、临时隐藏、截图暂停不改变模式。主页面复用 onboarding，展示 Logo、双语说明和“切换到窗口搜索”。导航与模式开关保留。
- 切换暂停旧查询、关闭筛选，原生撤销租约；未激活入口的 search/query-check/reveal 被拒绝，异步返回再检查当前模式。关闭胶囊及截图暂停取消在途查询。
- 两边保留各自搜索词、后缀和排序；打开工具页不再把胶囊草稿覆盖到窗口。共享索引继续运行，不改变范围或安装服务。
- 新增内部 query-check action，只接受当前入口的随机 ticket。对匹配项身份、名称、目录、后缀、大小、时间及核实状态计算无序摘要；数量相同的改名或替换仍可识别。摘要不是权限依据，定位仍按租约和路径校验。
- 每 1.5 秒至多一次有需要的静默检查；无关变化只更新校验版本及后缀，保留分页和滚动。相关结果变化时，空闲顶部可静默更新；已选中、滚动或打开筛选时才提示手动刷新。过期租约可静默重新查询。
- 初建/显式重建保留真实进度；完成初建后，常规复核保持就绪或部分可用。失败复核中未见到的旧条目才标待核实，按统一 policy 保护挂载子卷。
- 模式 generation 防倒退、轮询补读、后台检查取消共同阻止旧响应覆盖新模式。错误、离线和暂停仍明确显示。

## 契约与责任

新增 DOM：fileSearchCapsuleGuide、fileSearchUseWindow、fileSearchCapsuleStatus；新增中英三条文案。复用 onboarding 和按钮样式，Logo 圆角适配深色。

新增 file_search 内部 action query-check 与查询结果 fingerprint 字段；不新增顶层 Tauri command、权限、事件、storage key、CLI/MCP 能力或持久化迁移。

文件：features/file-search 的 controller/core/results/template/file-search.css、locales 中英字典；native_runtime/file_search 的 query/service/index/index_remote/mod/windows；相应浏览器 fixture、JS 和 Rust 测试。

## 验证

- JS focused：查询/IME/乱序取消、静默检查、切换丢弃迟到结果通过。
- 原生 focused：48 passed、9 ignored，包括未变目录复核不改版本、远程失败才标过期、同数量改名摘要及入口互斥。
- 浏览器工作台 51 项、渲染状态 15 项通过。包含 100 次无关变化、相关更新不闪 searching、刷新后不重复提示、草稿保留、双语、滚动、500 次筛选与 50 次重开。
- 真实 WebView2 隔离回归通过：跨入口租约拒绝、无关变更、同数量改名、100 次筛选折叠、动画反向与截图恢复。合成百万条输入到可操作 p50 171.3ms / p95 216.2ms（含防抖）。全匹配摘要增加部分核心查询工作，不宣传普遍提速。
- architecture/build、1,803 项 security-release、CLI/MCP 和产物审计通过；全量 Rust 315 passed、23 ignored。release 套件的 113 项经首次运行与定点重试全部完成：独立 npm 安装的官方审计接口曾 ECONNRESET，重试后审计与后续项目通过，不将网络错误当漏洞或产品故障。
- 最终源码快照的原生窗口补验通过（1 passed）：主窗口在胶囊模式下的直接查询/检查被拒绝；100 次筛选、选择和折叠未残留原生边框、结果窗口或菜单；动画反向与截图隐藏/恢复通过。
