# V3.3 冗余清理

日期：2026-11-05。本地分支 V3.3，版本 3.3.0，未发布。

## 基线与范围

- 用户确认文件搜索测试正常，已将此前 V3.3 开发成果保存为本地提交 849a114；没有远端推送。
- 扫描 515 个前端 JS 文件的局部函数/导入引用，并检查源码内容重复、当前构建入口、生成资源来源和 Git 待提交项。静态候选仅作线索，逐项核对调用与测试后才修改。

## 已实施

- application-runtime.js 删除 21 个未使用导入绑定，以及 2 个无调用包装函数。PPT 文本提取/压缩仍由各自懒加载入口使用原核心；没有更换算法。
- 音频提取/裁剪、PDF 合并/旋转/增强/安全模块共删除 6 个无调用的父目录辅助函数，实际输出定位继续使用现有共享/原生路径。
- 文件搜索页移除每次打开的 take-handoff 空请求和死分支，原生移除从不写入的 handoff 字段。旧 action 仍返回 null，主窗/胶囊草稿独立；无新 DOM、存储、事件、命令或迁移。
- Vite 不再监听临时输出、缓存和 CLI 自动暂存源码，避免无效重载及 EBUSY。回归以真实 Vite watcher 的注册清单检查源码在、产物不在；不把时间敏感的系统文件通知当稳定测试依据。
- 外联申请草稿仅从 Git 候选中排除，文件仍留在本地；CLI Office 驱动保留唯一源文件，生成副本忽略且继续由 prepack 暂存。发布审计补充拦截外联草稿及 V33 内部报告。
