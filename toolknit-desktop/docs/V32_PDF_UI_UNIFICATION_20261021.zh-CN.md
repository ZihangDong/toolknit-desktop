## 覆盖边界

PDF 分类共 16 项。文档画布覆盖编辑器、裁剪、页码、合并、拆分、旋转、PDF 转图像、PDF 转扫描件、PDF 转 Word、图像转 PDF，以及压缩结果图像。加密、解密、增强没有独立文档画布；文本提取和 AI Markdown 的结果是文本阅读区，继续滚动。所有缩略图、参数面板保留原滚动。

普通滚轮无需 Ctrl。触控板 deltaMode 归一化，帧内合并；缩放边界仍消费滚轮，防止突然滚页。可编辑画布使用中键/空格平移，普通左键继续编辑；只读图片/共享工作台可直接拖动。显示与后台高清重绘分开，后者以当前页/会话校验提交。

输入底线由 1 px 增至 3 px，220 ms 从左向右填充；白天黑色、深色白色。尺寸和内边距不变，背景层画在边框盒内部。组合搜索框由外层画线，历史悬浮搜索无动画。错误态保留错误色；按钮、checkbox、range、color 输入不接管。减少动态效果与 forced-colors 单独验证。

## 契约与兼容

- 保留原有 DOM ID、按钮事件、文件输出、Tauri 命令、存储键、CLI/MCP 接口。
- 新增共享 class：`tk-preview-viewport`、`is-preview-panning`、`tk-upload-empty`、`tk-upload-empty-pick`、`tk-file-result`；原组件 class 继续存在，废弃图像 PDF 自定义空状态/结果样式已清理。
- 本轮不修改原文件、不新增网络能力、不启用开发模式。测试使用合成 PDF/图片，网络请求在浏览器回归中隔离。
- 私有 Skill 保留在个人技能目录，不进入 Git 仓库和产品资源。

## 验证入口

- `npm run test:preview-viewport`：锚点、RAF、上下限、可编辑输入排除、清理、像素预算和迟到提交。
- `npm run test:pdf-input-interactions-browser`：10 类实际预览、双主题、连续移动锚点、平移、缩放上限、文件名/快捷键聚焦、空状态、真实生成 PDF 与窄窗口完成提示。

- 既有 PDF 编辑器、裁剪、转 Word、压缩浏览器回归，配合架构、发布、安全、CLI 和 Rust 门禁。
- 浏览器运行依赖 Playwright，可用 `NODE_PATH` 指向测试依赖，`TOOLKNIT_TEST_BROWSER` 指向 Edge/Chromium。构建和使用同一 dist 的浏览器回归必须串行。

本机测试证据在忽略目录 `tmp/pdf-input-interactions/`、`tmp/shared-input-focus/` 和 `tmp/v32-ui-*.log`，不随仓库发布。

## 已知限制

缩放锚点受画布边界约束：当纸张比视区小时，边界不能提供不存在的滚动空间。整体栅格预算优先控制内存，极高倍放大会有像素上限。Windows 安装版、多显示器触控板硬件及所有厂商 WebView2 版本未在本轮逐一验证；浏览器回归不冒充安装版验收。
