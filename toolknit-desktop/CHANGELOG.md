## v2.3.1 (2026-08-31)

### 安全与稳定性热修

- 正式构建关闭 WebView2 DevTools 和 F12 调试入口，并同时移除 Tauri `devtools` 编译特性。
- 背景移除模型目录只保留有完整官方来源和 SHA-256 校验的 MODNet；修复重复下载触发 `matting:download-busy` 及按钮异步异常未捕获的问题。
- Markdown 实时预览阻止远程图片和本机地址自动请求；外部 HTTP/HTTPS 链接改由经过校验的系统浏览器打开，不再导航主 WebView。
- 外链命令拒绝超长、控制字符、非 HTTP(S) 和凭据 URL；“打开文件夹”只接受真实存在的绝对文件或目录路径。
- 模型下载在响应体超过签名目录大小时立即中止，继续保留最终大小和 SHA-256 完整性校验。
- MCP stdio 增加 8 MB 原始消息上限、4 项活动调用上限、重复请求 ID 和非法 ID 类型拒绝，避免资源滥用。
- 系统盘环境变量改为严格盘符解析；自定义背景、硬件检测和 AI 解析日志不再记录用户路径、硬件载荷、文件名或模型返回正文。
- 发布版停止写入屏幕取色与硬件检测临时调试日志；运行时创建的取色 WebView 同样显式关闭 DevTools。
- AI API Key 从 WebView 明文存储迁移到 Windows 当前用户 DPAPI 加密文件；只有加密写入成功后才清理旧数据，保存或清除失败会明确提示且不会伪装成功。
- 自定义背景的 localhost 媒体服务增加每次进程随机的 128 位访问令牌，无令牌或错误令牌的本机请求不会读取背景文件。
- 移除未使用的翻译 HTML 直写入口，并避免控制台诊断输出完整文件对象或外部地址。
- AI HTTPS 响应改为流式执行 2 MB 上限，恶意或异常的 chunked 响应超过限制时立即取消，不再等整个响应进入内存后才拒绝。
- 新增原生 WebView 导航守卫，外部页面无法装入主窗口或辅助窗口；原生外链失败时不再回退到未受控的 `window.open`。
- CSP 明确禁止对象、子页面、基址和表单外发；GitHub Actions 全部固定到完整提交 SHA。
- 新增发布安全门禁，自动检查 DevTools、CSP、Tauri 权限、资源作用域、CI 供应链、敏感文件、发布日志与 API Key 加密存储等安全边界。

### 版本与兼容性

- 桌面端、Tauri、Rust crate 与 `@toolknit/cli` 统一升级为 `2.3.1`；65 个桌面工具、12 个分类和 46 项 CLI/MCP 能力保持不变。
- 安装器继续内置 WebView2 引导程序；本版本暂不进行 Authenticode 代码签名。

## v2.3.0 (2026-08-31)

> 原规划的 2.2.0 未单独发布，其更新体验能力并入本版本。

### 新增工具

- 文本与转写分类新增“提词器”：粘贴台词或读取 TXT、Markdown、DOCX、PDF 文稿，支持平滑滚动、速度与字号调节、水平/垂直镜像和专注模式；句子级语音跟随提供自动选择、Windows 系统识别与 ToolKnit 离线识别（whisper.dll 本地推理）三种方式，关闭页面时停止麦克风、取消未完成识别并释放模型会话。
- PDF 分类新增“PDF 加页码”：把一个或多个 PDF 展开成统一页面序列，支持页面排序、范围选择、跳过封面、连续或分文件编号、起始值与步长、自定义文本模板、九宫格位置与多种外观样式；页码由 PDF 矢量指令直接写入，可导出单个 PDF 或逐页 ZIP。
- PDF 分类新增“PDF 裁剪”：在可视化预览中框选保留区域或输入精确边距（毫米 / PDF 点），支持全部页面统一裁剪与单页独立调整、撤销重做；裁剪通过修改页面边界实现，不会截图压缩，可导出单个 PDF 或逐页 ZIP。
- 图像分类新增“背景移除”：使用按需下载的本地抠图模型生成透明背景，支持前后对比、边缘优化、背景颜色预览和原始分辨率导出；模型推理和图片处理均留在本机。
- PDF 分类新增“Excel 转 PDF”：批量读取 XLSX、XLS 和 ODS，支持工作表范围、方向、纸张与缩放设置；使用 ToolKnit 管理的本地 LibreOffice 运行时渲染，并针对 WPS 工作簿提供兼容导入路径。
- 三项新工具统一使用自定义下拉组件，保持键盘可访问与玻璃拟态视觉的一致性。

### 更新体验

- 启动后的空闲时段后台检查已发布的 GitHub Release，不打断当前工作；全屏更新页集中呈现当前版本、可用版本、更新说明与已验证的 Release 地址。
- 选择“我还不想更新”将当前版本延后 24 小时；更高的新版本不会被旧延后记录隐藏。
- Release 元数据仅在本机缓存六小时；检查过程不发送工具输入、文件路径、账户信息或使用历史；远端 Markdown 只作为文本呈现，不会执行其中的代码。

### 修复

- 提词器：进度条与已用 / 剩余时间改为跟随真实滚动位置匀速前进，不再按句子序号跳变，也不会在长句播放时长时间冻结在 0%。
- 提词器：滚动速度按界面显示的预估时长自动推导，整个文稿的实际滚动时长与显示时长一致，调整字号或篇幅后不再出现“几乎不播放”或“进度条跑很快”。
- 提词器：修复 “GLM-5.3”“2.3.0”“3.14” 等数字中的英文句点被误判为句子边界的问题；数字后跟空格的编号列表仍正常切分。
- 提词器：修复播放 / 暂停图标在句间切换后消失的问题。
- 提词器：修复程序化滚动后当前句同步可能永久失效，导致进度、高亮和自动结束全部冻结的问题。
- 提词器：低帧率设备上播放不再随掉帧等比例变慢；播放期间暂停 WebGL 背景渲染，减少起播与滚动掉帧。
- 提词器：播放滚动改为合成器驱动的 transform 平移（浮点亚像素精度），不再受显示缩放的物理像素网格量化影响——低速倍速（如 0.4x、1.0x）下不再出现卡顿和步进抽搐，任何倍速都能吃满屏幕刷新率匀速滚动；播放期间主线程不再逐帧重绘文字，进一步降低掉帧。镜像（水平/垂直）并入同一变换矩阵并修正了应用顺序，垂直镜像下滚动方向保持正确；暂停时浮点偏移落回原生滚动，滚轮、点句定位等手动交互不受影响。
- 提词器：播放期间说明栏收起动画不再触发重复的视图重新定位，消除起播瞬间的顿挫。
- 提词器：暂停与播放改为原地冻结、原地继续——不再自动重新定位当前句，起播后进度也不会瞬间前跳；播放期间面板收展与窗口缩放同样不会移动视图。
- 提词器：控制栏改版——速度与字号改为渐升“音波”拖动条（50 根竖线、当前值以左点亮），支持拖动、点击与键盘微调，拖动时浮出数值徽标；播放 / 暂停改为白色平面图标；键盘 +/− 快捷键保留并与滑条双向联动，滑条聚焦时方向键只调节取值。
- 提词器：桌面端语音跟随放开 WebView2 媒体权限，麦克风不再被静默拒绝；配合已下载的离线识别模型即可逐句跟随，系统识别能力仍取决于 WebView2 环境。
- 提词器：离线识别模型未安装时，首页工具卡片点击直接弹出依赖下载引导（与音视频提取文字一致的拦截流程），不安装无法进入工具页；下载完成后自动进入，语音跟随启动中遇到模型缺失也会重新弹出门引并自动恢复跟随。
- 提词器：语音跟随新增逐字阅读光标——当前朗读位置下方显示白色短光标条，随识别实时前进；语音跟随模式下加大行距以容纳光标；识别结果中的常见繁体字自动映射为简体参与匹配，避免繁体输出导致跟随失效。
- 提词器：语音跟随实时窗口从 4.2 秒缩短到 3.2 秒，首条识别与后续跟随更快；音频上下文无法运行时立即明确报错而不是静默无声。
- 音视频提取文字：识别结果中的常见繁体字自动重写为简体后再发布（JSON / SRT / TXT 同步处理），桌面端与 CLI 转写一致，不再出现“识别内容正确但混入繁体”的问题。
- 工具页顶栏统一：提词器补齐“返回”按钮与 TOOL PAGE 页签，替换原品牌标识；“网页端版本”文案统一为“网页版本”，修复文本格式化页网页链接的下划线，支持作者按钮在提词器页恢复标准白底样式。
- PDF 工具：修复在 WebView2 / 浏览器内核低于 Chromium 140 的设备上，所有 PDF 工具加载文件即报 “hashOriginal.toHex is not a function” 的问题。原因是 pdf.js 6.x 的 modern 构建依赖 `Uint8Array.prototype.toHex` 等新 API 计算文档指纹；桌面端全部 12 处引用切换为官方 legacy 构建（自带 polyfill），与 CLI 侧既有做法一致，pdfjs-dist 版本与安全修复保持 6.2.108 不变，worker 体积增加约 160 KB。

### 版本与界面标识

- 桌面应用、Tauri、Rust crate 与 `@toolknit/cli` 统一升级为 `2.3.0`；首页海报、设置页、帮助中心与全部工具页的视觉版本标识同步为 2.3。

- 核心颜色转换与输入交互方案由 Joshua-Zion 通过 [PR #23](https://github.com/ZihangDong/toolknit-desktop/pull/23) 贡献，并完成 ToolKnit 2.1 主题、懒加载、生命周期和轨道渲染性能适配。
- 新增“开发者工具”分类，提供 JSON 格式化、Base64 编解码、URL 编解码、UUID v4 批量生成、JWT 查看器和 Hash & Crypto 共 6 项本地工具。
- Hash & Crypto 覆盖摘要、文件 Hash、HMAC、AES、DES、3DES、SM4、RC4、ChaCha20、Trivium、RSA 与 SM2 等 17 类模块；旧算法明确标记为仅兼容用途。
- C 盘清理完成风险分级、只读扫描和确认流程，并正式纳入 2.1 的 60 项桌面工具目录。相对上一版 49 项目录，本次净增 11 个工具入口。

### 工作台与交互

- 新增图片和视频自定义壁纸，首页、分类页、工具页与收藏卡片统一为可读性更高的玻璃拟态视觉。
- 工具卡片加入克制的水膜波纹悬停反馈，并统一分类胶囊、输入框、下拉菜单、Toast、按钮与中英文错误提示。
- 支持作者改为独立页面并复用完整顶部导航；开发者手记支持随机轮播、进度、暂停和继续。
- 首页、设置和反馈流程完成自适应排版；功能建议直接打开 GitHub Issues，移除不再使用的抽屉表单。

### 新工具性能与生命周期

- Markdown、颜色替换、开发者工具和密码算法模块按需加载；关闭页面时终止 Worker、任务、监听器、计时器、Canvas 缓冲与 Blob URL。
- 智能颜色替换使用降采样 Worker 预览、过期任务淘汰和原始分辨率原生导出，连续调参不会让旧结果覆盖新结果。
- 文件 Hash 与认证文件加解密采用流式原生处理，支持进度、取消、临时文件清理和成功后的安全发布。
- AES 文件模式使用版本化 `.tkaes` 容器、Argon2id 密钥派生和 AES-256-GCM 分块认证；错误密码或损坏容器不会留下不完整输出。
- 设置页优先快速检测并复用电脑上已有的 FFmpeg 与 LibreOffice，仅在缺失时提示下载运行时。

### PDF 工作流加固

- PDF 编辑器补齐页面全选、反选、复制、插入空白页、可重复编辑文字、源页面旋转预览和安全的未保存修改确认。
- 完整原始顺序的编辑器导出保留表单和文档元数据；重排、跨文件合并等重建路径会清理失效 Widget。
- PDF 加密迁移到桌面端 qpdf AES-256，支持 Unicode 密码、权限设置和表单/元数据保留；错误密码、超长密码和不可用引擎均明确反馈。
- PDF 增强使用统一渲染预算、损坏校验、分块临时会话和排他原子发布，不会覆盖已有文件或留下半成品。
- PDF 压缩在没有实际体积收益时不生成误导性的“成功文件”，批量结果只统计真实保存项。

### 图像与安全

- 图像转换和压缩统一处理 EXIF 方向、透明图像 JPEG 白底合成，并允许坏文件逐项失败而不丢失同批成功输出。
- 图像批处理完成面板展示具体失败项；原生像素回归覆盖透明通道、方向、WebP 无损和损坏输入。
- Markdown 预览使用 DOMPurify 清理文档内容；Mermaid 输出为静态 SVG，自包含 HTML 导出无需联网即可查看。
- 密码、密钥、私钥、IV、原文和运算结果不会进入 localStorage、日志或持久历史；页面内历史仅存在于当前会话。
- RSA PKCS#1 v1.5 兼容模式迁移到 Windows CNG，移除存在已知时序风险的旧实现；Rust 依赖升级到已修复版本，并在 CI 与正式发布流程加入 RustSec 审计门禁。
- 修复自定义 AI 服务地址的私网 HTTP 授权边界，拒绝公网 HTTP、凭据 URL、代理和重定向跟随。
- 修复硬件检测中高位 GPU 显示值溢出导致的读取失败。

### 发布质量

- CLI 资源 staging 纳入 PDF 结构模块并加入发布包合同测试。
- 桌面端扩展为 12 个分类、60 项工具；桌面应用、Tauri、Rust crate 与 `@toolknit/cli` 版本统一升级为 `2.1.0`。

## v1.2.8 / v1.2 (2026-08-04)

### 桌面端与本地工作流

- 首页重构为最近使用、推荐工具、我的收藏、支持作者与开源数据展示；保留动态背景和中英双语体验。
- 设置页支持统一输出根目录，并按工具二级分类保存；支持自定义图片或视频背景，失效时自动回退默认视觉背景。
- 所有会产出文件的桌面工作流使用统一完成弹窗、唯一命名和原子写入，避免覆盖原件或留下半成品。
- 窗口固定为 1160 x 780；关闭按钮默认隐藏到系统托盘，托盘菜单可显式退出程序。

### 工具能力

- PDF 合并、拆分、旋转、加密/解密、压缩和增强完成输入校验、选页、预览和输出安全收口。
- 音频转换、剪辑、提取和 BPM 分析，以及视频格式转换、高清单帧截取和最长 30 秒 GIF 截取完成本地处理契约。
- 新增长图拼接，支持图片与 PDF 页导入、横竖拼接、间距/背景/参考尺寸、取消、进度和输出预览。
- 音视频转文字使用可下载的本地 Whisper 模型，支持中文/英文转写、TXT/SRT/JSON 输出，以及可选 DeepSeek 二次润色。

### AI 文档与 AI 表格

- AI 文档输出可编辑工程、干净预览和编号图；桌面端与 IDE Agent 都可按稳定控件编号修改位置、尺寸、样式、对齐、层级、图像和表格。
- AI 表格输出 XLSX/CSV/PDF/PNG、可编辑工程和预览；支持稳定行列图表编号、试运行、修改、撤销、图表和公式注入防护。
- DeepSeek/OpenAI 兼容调用增加严格结构校验、有限重试、页数验证和输出原子发布。

### CLI、MCP 与依赖

- 发布独立 `@toolknit/cli`，支持 PDF、音频、视频、文本、颜色、长图拼接、离线转写、AI 文档与 AI 表格命令及 MCP 工具。
- 提供中英文 Agent 手册、自然语言提示词、结构化进度、退出码、JSON 输出和不污染 MCP stdio 的 ASCII 横幅。
- FFmpeg 与 Whisper 模型使用官方源/国内镜像按需下载；下载具备校验、断点续传和状态检查。

### 质量与安全

- 修复并验证文件锁定、输出碰撞、符号链接、损坏输入、取消、中途失败和自定义背景媒体 Range 请求等边界场景。
- 移除未使用的 `xlsx` 高危依赖，升级受影响的依赖树并将完整 npm 审计收敛到零漏洞。
- 发行前回归覆盖 PDF、AI 文档/表格、图像、音视频、长图拼接、CLI/MCP、依赖契约与 23 项 Rust 原生测试。

## 1.0测试版 / v1.0 Beta (2026-06-30)

ToolKnit 桌面客户端首个公开测试版正式上线。所有文件在本地处理，无需上传云端，随时随地离线可用。

### 核心亮点

- **桌面客户端首发**：Windows 原生 .exe 应用，安装即用，支持深色主题与 WebGL 动态背景，延续网页版一致的视觉体验。
- **中英双语界面**：一键切换 中文 / English，全部工具文案、提示与按钮均已完成本地化。
- **蜘蛛精灵加载动画**：页面切换与工具处理过程中加入专属蜘蛛吉祥物过渡动画，让等待不再枯燥。
- **统一安装器**：可视化安装向导，支持自定义安装路径、桌面快捷方式、开始菜单入口，以及语言偏好记忆。

### 已集成的工具套件

- **PDF 工具箱**：PDF 转图片、拆分、合并、压缩、旋转、加密/解密、格式转换、页码提取、水印处理等。
- **图片工具箱**：格式转换、批量转换、压缩、批量压缩、图片去水印、裁剪、拼图等。
- **音频工具箱**：格式转换、音频剪辑、音频提取、BPM 检测、声道处理等。
- **视频工具箱**：格式转换、视频截图、视频压缩等。
- **文本工具箱**：全角半角转换、文本反转、简繁转换、大小写转换、文本格式化等。
- **AI 创意助手**：AI 翻译、AI 润色、AI 文档生成、AI 角色扮演等。

### 使用体验

- **离线优先**：所有工具不依赖网络，本地运行，隐私文件无需上传。
- **拖拽处理**：PDF、图片、音频、视频等文件支持拖拽导入，操作直观。
- **批量处理**：图片、音频等工具支持批量导入与一键导出，提升工作效率。
- **导出路径记忆**：设置页可自定义默认保存位置，后续导出自动沿用。
- **侧边栏导航**：首页、PDF、图片、音频、视频、AI 等分类清晰，工具快速定位。
