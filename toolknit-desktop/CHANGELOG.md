## v1.2.7 / v1.2 发行候选 (2026-08-03)

### 桌面端与本地工作流

- 首页重构为最近使用、推荐工具、我的收藏、支持作者与开源数据展示；保留动态背景和中英双语体验。
- 设置页支持统一输出根目录，并按工具二级分类保存；支持自定义图片或视频背景，失效时自动回退默认视觉背景。
- 所有会产出文件的桌面工作流使用统一完成弹窗、唯一命名和原子写入，避免覆盖原件或留下半成品。
- 窗口固定为 1160 x 780；关闭按钮默认隐藏到系统托盘，托盘菜单可显式退出程序。

### 工具能力

- PDF 合并、拆分、旋转、加密/解密、压缩和增强完成输入校验、选页、预览和输出安全收口。
- 音频转换、剪辑、提取和 BPM 分析，以及视频格式转换、高清单帧截取和最长 30 秒 GIF 截取完成本地处理契约。
- 新增长图拼接，支持图片与 PDF 页导入、横竖拼接、间距/背景/参考尺寸、取消、进度和输出预览。
- 音视频转文字使用可下载的本地 Whisper 模型，支持中文/英文转写、TXT/SRT/JSON 输出，以及可选 DeepSeek 二次润色。

### AI 文档与 AI 表格

- AI 文档输出可编辑工程、干净预览和编号图；桌面端与 IDE Agent 都可按稳定控件编号修改位置、尺寸、样式、对齐、层级、图像和表格。
- AI 表格输出 XLSX/CSV/PDF/PNG、可编辑工程和预览；支持稳定行列图表编号、试运行、修改、撤销、图表和公式注入防护。
- DeepSeek/OpenAI 兼容调用增加严格结构校验、有限重试、页数验证和输出原子发布。

### CLI、MCP 与依赖

- 发布独立 `@toolknit/cli`，支持 PDF、音频、视频、文本、颜色、长图拼接、离线转写、AI 文档与 AI 表格命令及 MCP 工具。
- 提供中英文 Agent 手册、自然语言提示词、结构化进度、退出码、JSON 输出和不污染 MCP stdio 的 ASCII 横幅。
- FFmpeg 与 Whisper 模型使用官方源/国内镜像按需下载；下载具备校验、断点续传和状态检查。

### 质量与安全

- 修复并验证文件锁定、输出碰撞、符号链接、损坏输入、取消、中途失败和自定义背景媒体 Range 请求等边界场景。
- 移除未使用的 `xlsx` 高危依赖，升级受影响的依赖树并将完整 npm 审计收敛到零漏洞。
- 发行前回归覆盖 PDF、AI 文档/表格、图像、音视频、长图拼接、CLI/MCP、依赖契约与 21 项 Rust 原生测试。

## 1.0测试版 / v1.0 Beta (2026-06-30)

ToolKnit 桌面客户端首个公开测试版正式上线。所有文件在本地处理，无需上传云端，随时随地离线可用。

### 核心亮点

- **桌面客户端首发**：Windows 原生 .exe 应用，安装即用，支持深色主题与 WebGL 动态背景，延续网页版一致的视觉体验。
- **中英双语界面**：一键切换 中文 / English，全部工具文案、提示与按钮均已完成本地化。
- **蜘蛛精灵加载动画**：页面切换与工具处理过程中加入专属蜘蛛吉祥物过渡动画，让等待不再枯燥。
- **统一安装器**：可视化安装向导，支持自定义安装路径、桌面快捷方式、开始菜单入口，以及语言偏好记忆。

### 已集成的工具套件

- **PDF 工具箱**：PDF 转图片、拆分、合并、压缩、旋转、加密/解密、格式转换、页码提取、水印处理等。
- **图片工具箱**：格式转换、批量转换、压缩、批量压缩、图片去水印、裁剪、拼图等。
- **音频工具箱**：格式转换、音频剪辑、音频提取、BPM 检测、声道处理等。
- **视频工具箱**：格式转换、视频截图、视频压缩等。
- **文本工具箱**：全角半角转换、文本反转、简繁转换、大小写转换、文本格式化等。
- **AI 创意助手**：AI 翻译、AI 润色、AI 文档生成、AI 角色扮演等。

### 使用体验

- **离线优先**：所有工具不依赖网络，本地运行，隐私文件无需上传。
- **拖拽处理**：PDF、图片、音频、视频等文件支持拖拽导入，操作直观。
- **批量处理**：图片、音频等工具支持批量导入与一键导出，提升工作效率。
- **导出路径记忆**：设置页可自定义默认保存位置，后续导出自动沿用。
- **侧边栏导航**：首页、PDF、图片、音频、视频、AI 等分类清晰，工具快速定位。
