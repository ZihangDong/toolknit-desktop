SYSTEM CLEANUP · TOOL PAGE 3.1
System Cleanup

C盘清理

按低、中、高三个风险档清理系统缓存与临时空间，清理前会完整说明影响。

使用提示
  • 建议从低风险档开始清理，空间仍不足时再考虑中、高风险档。
  • 清理为永久删除且不会进入回收站，请先阅读右侧说明再确认。
  • 清理前请关闭正在占用相关文件的程序，避免文件被占用而跳过。
PROTECTED

以下内容不会被清理

清理只针对缓存、临时文件和系统空间项，绝不扫描或删除你的个人文件。

  • 下载、文档、桌面、图片、音乐、视频
  • 微信 / QQ 聊天记录与文件
  • WPS / Office 备份与自动恢复文件
  • 浏览器书签、密码与登录状态（仅清理缓存）
  • 已安装应用及其个人数据

三步完成清理

  1. 01
    自动扫描

    进入页面后自动扫描每个风险档的可释放空间，无需手动选择目录。

  2. 02
    选择档位

    在左侧选择低、中或高风险档，右侧会实时显示清理内容与影响。

  3. 03
    确认清理

    阅读确认弹框并等待 5 秒倒计时后，即可一键清理当前档。

需要管理员权限

C盘清理涉及系统级缓存，需要以管理员身份运行 ToolKnit 才能完整执行。

也可以右键右下角任务栏中的 ToolKnit 退出，再回到桌面右键图标，选择“以管理员身份运行”。

确认清理

清理为永久删除，不会进入回收站。
