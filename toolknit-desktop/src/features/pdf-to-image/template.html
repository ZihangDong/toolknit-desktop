PDF To Image

PDF 转图像

选择需要转换的 PDF 页面，逐页导出清晰图像，或按顺序生成便于阅读的长图。

LOCAL ONLY 文件只在本机处理，不上传服务器。
01
上传文件

添加一个 PDF 文件后，进入页面预览和选择。

02
选择页面

在页面选择区勾选需要导出的 PDF 页码。

03
选择格式

可导出 PNG、JPG、WebP，或生成长图。

04
导出结果

按选中页生成图像文件并保存到本机。

DROP OR SELECT

把要转换的 PDF 放到这里

文件载入后会进入页面选择区，你可以按页导出图像，或把选中的页面拼成长图。
