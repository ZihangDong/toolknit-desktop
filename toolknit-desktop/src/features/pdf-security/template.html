02

PDF Decryptor

PDF 文件解密

移除 PDF 密码和权限限制，输入正确密码即可解锁，纯本地处理。

LOCAL ONLY 文件只在本机处理，不上传服务器。
01
添加文件

选择一个 PDF 文件，准备输入正确密码。

02
输入密码

输入并确认 PDF 密码后进入解密流程。

03
移除限制

解密后将同时移除打印、复制等限制。

04
导出结果

解密后的 PDF 会保存到本机目录。

DROP OR SELECT

把要解密的 PDF 放到这里

上传后进入文件队列，输入密码后即可执行解密并导出新的 PDF。

解密后导出到本地，安全可靠
