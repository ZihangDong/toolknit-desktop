Text Tool

文本格式化

大小写转换、清理空行空格、排序去重、添加行号，一键处理文本。

LOCAL ONLY 文档只在本机读取，格式化结果不会上传服务器；适合名单、日志、文案、代码片段和资料清洗。
01
输入或上传

直接粘贴文本，或读取 TXT / Markdown / DOCX / PDF 等文档。

02
选择动作

从大小写、空格、行处理、排序和全半角中选择一种处理。

03
检查结果

右侧实时展示处理结果，确认后复制或继续作为输入。

04
连续处理

把结果作为下一轮输入，可叠加多种文本清洗步骤。

处理动作
