## About the project and me

<p><img src="assets/readme/v3.1/spider-wave.svg" alt="The ToolKnit spider blinks and waves hello" width="88" height="88" /></p>

Hi, I am Zihang Dong, an independent developer turning everyday annoyances into small tools.
ToolKnit is a spider weaving a growing web. Each need adds a thread and becomes a tool. People discover it, use it and help improve it.
The boy is me; the spider on his head is the toolbox's little companion.

### Try the web app first

Open **[ToolKnit.com](https://toolknit.com)** in a modern desktop or mobile browser. No installation needed.
**95 web tools** cover PDF, images, audio, video, text, calculators, time, creative tasks, AI and self-tests.
Most need no account. Supported file tasks run locally in your browser. Network requirements are listed in each tool.

### Then bring it to your desktop

For everyday file work, [install the Windows app](https://toolknit.com/exe.html). V3.2 contains **73 tools**, with PDF to Word, Images to PDF, expanded floating history and saved phrases.
Set an output folder and favorite your tools. Install models only when needed.
Enable **one-click recording mode** for startup, clipboard monitoring and floating history. Press `Alt + Q` to capture.
The home page's V3.2 feature filter groups six new or enhanced tools.
See [Get started](#08--get-started) for installation requirements and instructions.

## 01 / Fewer apps, more things done

[↑ Back to contents](#contents)

Start with one small tool, then weave more of the desktop's everyday friction into one web.

Crop a PDF page. Find the text you just copied. Annotate a screenshot. Remove an image background.
Small jobs often mean switching between several applications.

ToolKnit brings PDF, PPT, image, audio, video, text, system and developer tools together.
Use the desktop app for local files, the web app for quick access, and CLI or Agents for suitable automated workflows.

## 02 / Keep the things you want to remember

[↑ Back to contents](#contents)

![The boy enables recording, copies a note and captures a screenshot; the spider stores them in history](assets/readme/v3.1/02-record.webp)

**Enable one mode in Settings to bring three features together.**

| Enabled together | What it does |
| --- | --- |
| Start with Windows | Keeps ToolKnit ready in the system tray after a restart |
| Live clipboard monitoring | Records newly copied text, images and file paths |
| Floating history | A draggable Logo opens shared clipboard images, text and file records with type filters |

Recording is opt-in and can be paused. Turning the mode off restores previous settings. Each switch also works independently.
Dismiss the home prompt for this session or permanently. The Settings switch remains available.
No keystroke or browsing logging. Monitoring stops when the application fully exits.

## 03 / A screenshot is just the start

[↑ Back to contents](#contents)

![The boy captures a region, annotates it, extracts and translates text, then pins the picture](assets/readme/v3.1/03-screenshot.webp)

**Press `Alt + Q` by default to capture a window or region.** You can change or disable the shortcut.

Add shapes, arrows, pen strokes, mosaic and text. Undo, redo or hold to compare with the original.
Text handles fit the content. The text editor has a quick-copy button.
Copy, save PNG / JPG or open the pinned viewer. Reveal a saved file in its folder and exit capture mode.
Find the tool under Creative. Screenshots share history with content copied from other apps; older images can be reopened.

| Task | How it works |
| --- | --- |
| Extract text | Local Windows OCR; small text, complex backgrounds and layouts can reduce accuracy |
| AI extraction | Sends the selected region to your configured image-capable model for text extraction |
| Screenshot translation | Requires the local Chinese / English model installed in Settings; recognition is followed by local translation and an image overlay |

Screenshot translation supports **Chinese and English only**. Without AI configuration, local OCR feeds the local translator.
With image-capable AI configured, OCR locates text and AI corrects it before local translation.
If AI fails, you choose whether to use OCR instead. The full translation remains copyable even when it cannot fit.

Translation components are downloaded on demand: approximately **192 MiB downloaded / 225 MiB installed**, separate from the main installer.
External AI latency depends on the provider. There is no fixed completion-time guarantee. Check recognition and translation results.

## 04 / Find what you copied

[↑ Back to contents](#contents)

![The spider retrieves text and a picture from clipboard history; the boy opens the picture in a pinned viewer](assets/readme/v3.1/04-clipboard.webp)

**The note you copied a moment ago does not have to disappear.**

Text, images and file paths stay in a searchable timeline. Filter, favorite and store records with local encryption. Monitoring preferences survive restarts.

| Action | How it works in V3.2 |
| --- | --- |
| Browse floating history | Shares the full history database; shows the first 20 records, type filters and detailed timestamps |
| Search and annotate | Searches content, source and notes as you type; right-click to add a note or delete |
| Reorder | Use the drag handle; new records enter at the top, displaced records remain in full history |
| Save phrases | Add a title and content, or save a text record; search separately and delete manually |
| Copy and drag | Click a phrase to copy; drag phrases, history text and original images into other apps |
| Inspect images | Thumbnails in the list, originals in the viewer; pin images on the desktop |
| Manage the window | Rounded context menus, shortcuts to the main app and history, or hide until ToolKnit restarts |

The recording switch sits at the bottom with a slim scroll indicator. Off-screen windows slide back into view.
Click the menu button again to collapse it. Opening history restores the main window. Copy feedback appears at the primary screen's bottom without taking focus.
Drop support depends on the receiving app. **Dragging never sends a message automatically.** Saved phrases survive history clearing and rotation.

Only newly copied content is recorded. Windows Win + V history is not imported. Pause or clear sensitive records as needed.
A Windows-account-protected backup can restore a missing key file. Without a usable key, the old database is preserved; **lost encrypted content is not guaranteed to be recoverable**.

## 05 / Keep file work in one place

[↑ Back to contents](#contents)

![The boy works with PDF and PPT files while the spider keeps one copy and recycles duplicates](assets/readme/v3.1/05-files.webp)

**Move from preview to output with fewer detours.**

| Workflow | Common tasks |
| --- | --- |
| PDF | Merge, split, crop, page numbers, rotate, export images / Word, compress, encrypt, decrypt, edit and extract text / Markdown |
| PPT | Export PDF / images, extract pictures and text, compress, generate AI outlines or editable PPTX drafts |
| Excel | Convert XLSX / XLS / ODS to PDF; select all or visible sheets, paper size, orientation and scaling |
| Cleanup | Analyze large files, clean C drive and scan duplicates by file type |

### PDF to Word: convert, then edit

Local analysis reconstructs text, paragraphs, tables and columns into editable DOCX. No Python, Office, GPU or extra model needed.
Handles papers, contracts, ebooks, invoices, quotes and common tables. Improves Chinese fonts, reading order, spacing and pagination.

| Option | Purpose |
| --- | --- |
| Preserve original pages | Keeps source page sizes and content positions, prioritizing layout |
| Continuous A4 layout | Fits content to A4 and splits pages at safe content boundaries |
| Start editing | Change text, delete content or replace images; automatic font sizing, undo, redo and reset |
| AI layout assistance | Optional image-capable AI reviews local structure; keeps source text and supports continuing after timeouts |

Three panes: settings, preview and page navigation. Select pages, cancel processing or export a fresh result.
Fixes include table backgrounds blocking text, short fields becoming images and reader-specific spacing.
Complex formulas and uncertain regions remain local images. **No scan OCR. Not every element will be editable or render identically in every reader.**
Limit: **64 MiB / 100 pages per file**. Only enabled AI processing sends necessary regional images and text.
**This custom engine has a separate source license. Commercial and noncommercial reuse both require written permission.** [Read the terms](#separate-pdf-to-word-engine-terms).

### Images to PDF: turn pictures into a document

- JPG, PNG, BMP, WebP, GIF and common TIFF files. Multi-page TIFF expands; animated files use the first frame.
- Drag to reorder, rotate or remove. Choose A4, original dimensions, margins and orientation.
- Original color, grayscale or scanned-style output, with three quality levels. Transparency becomes white.
- Up to 100 pages, 64 MiB per image. Processes one page at a time, with cancellation, retries and unique output names.

### PDF editing and selection: start with a blank page

Create a blank A4 PDF without uploading a file. Add multiline text, images and shapes, with undo and redo.
Improves rotated-page editing, edge placement and preview/export consistency. Fixes missing images after undo and stale state on rapid reopen.

The split workspace starts with no pages selected. Enter `1-10`, then `15-20`, to select **16 pages** without `11-14`.
Select all, enter a single page or overlap ranges without duplicates. Multiple files use continuous numbering. Each addition clears the input for the next range.

Zoom PDF previews around the pointer with the wheel. Pan with the middle button or Space. Sidebars and text areas still scroll.
Shared navigation, themes, input underlines and completion dialogs reduce flashing and clipped controls.

### Output and cleanup

Excel's All worksheets option includes hidden sheets and changes only a temporary copy. Text-layer PDF extraction needs no AI key. Use the separate AI vision tools for scanned text.
Duplicates are checked by content. Nothing is selected for deletion by default. Keep at least one copy per group; confirmed files are rechecked before moving to the Recycle Bin.

File tools preserve originals by default and write results to the output directory.
**Visual covering in the PDF editor is not secure redaction**, and a scanned-style PDF does not prevent copying.
Cleanup safeguards cannot replace your judgment about your files.

## 06 / A workbench for pictures and sound

[↑ Back to contents](#contents)

![The boy and spider work with a photo, filmstrip and waveform on a sparse black-and-white desk](assets/readme/v3.1/06-media.webp)

Crop, compress, convert and stitch images; generate icons or remove backgrounds with a local model.
Convert audio and video, trim audio, extract sound, capture video frames, create GIFs, transcribe offline and edit Markdown.

FFmpeg, LibreOffice, transcription and background-removal models are installed on demand. Existing usable runtimes are reused where supported.
Downloads support source fallback, resume and integrity checks. Failed updates preserve usable components. Network speeds vary.
Background removal offers CPU mode. Automatic mode retries on CPU after GPU failure. Missing components get a specific error.
WPS / Microsoft Office is not LibreOffice and cannot replace workflows that need `soffice`.

### Local first, with clear boundaries

Ordinary file tasks run locally by default. When you actively use an AI feature, necessary file content or screenshot regions are sent to your configured provider.
Dependency downloads and update checks need a connection; installed offline capabilities do not require an AI key.
File-size, page, pixel and batch limits vary by tool; support is not unlimited for every format.

## Run and build from source

[↑ Back to contents](#contents)

### Prerequisites

**Confirm authorization before running the source.** This branch includes the PDF-to-Word Engine.
Running, testing or building the complete app with that Engine requires prior written permission. Reading the source does not.
Normal use of official apps and the official CLI follows their applicable terms. See the [Engine license](LICENSES/ToolKnit-PDF-Word-Source-View-1.0.md).

Use a supported Windows 10 / 11 system with Node.js **22.13+** (24 recommended), Rust stable **1.90+**, Visual Studio C++ Build Tools (Desktop development with C++ and Windows SDK), and Microsoft Edge WebView2 Runtime.
Initial npm and Rust dependency installation requires a connection. Install using the existing lockfiles.

### Start the desktop app

```powershell
git clone --branch V3.2 https://github.com/ZihangDong/toolknit-desktop.git
Set-Location toolknit-desktop\toolknit-desktop
npm ci
npm run tauri dev
```

This checks out `V3.2`. Once authorized, run `npm run dev` for a frontend preview at `http://localhost:1420/` by default.
Native files, the system tray and global screenshots need the Tauri desktop environment.

### Build an installer

From the nested `toolknit-desktop/` directory:

```powershell
npm run build:release-package
```

Builds the frontend, then the desktop app. Production settings disable DevTools. Code signing needs separate configuration.
Default NSIS output: `src-tauri/target/release/bundle/nsis/`. A custom Cargo target directory changes that location.
FFmpeg, LibreOffice and optional models are installed on demand. Source code does not include user keys or complete model packages.
