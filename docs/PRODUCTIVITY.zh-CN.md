# 文件工作台（V3.4 开发版）

首页搜索“批量重命名”“任务中心”或“工具串联”即可进入，也可在清理工具分类打开。三个页面共用顶部切换入口，支持现有明暗模式和配色。

## 批量重命名

添加或拖入最多 500 个文件。命名模板支持 `{name}`（不含最后一个扩展名的原名称）、`{n}`（序号）、`{date}`（本地日期）。扩展名自动保留；可设置起始序号、位数，以及普通或正则查找替换。序号按列表顺序生成，可先按名称排序。

右侧实时预览新名称。目标名称重复、Windows 保留名称和非法字符会阻止执行；实际修改前，原生端再次检查磁盘冲突。执行过程中不能取消。文件在原目录改名，通过暂存处理文件名互换；已有目标文件不会被覆盖。文件系统需要支持硬链接，不支持时操作会安全失败。

“撤销上次重命名”恢复最近一批文件的名称，重启应用后仍可使用。再次重命名会替换这条撤销记录。文件在改名后被修改、移动或发生名称冲突时，撤销会停止并给出提示。发生异常恢复错误时，错误信息会列出保留的暂存文件；应用数据目录中的 `batch-rename-pending.json` 记录待恢复映射，存在此文件时不会继续修改新一批文件。

浏览器预览可以测试规则；实际修改本机文件需要桌面版。

## 任务中心

当前记录范围：批量重命名与撤销、工具串联、Word 转 PDF、PDF 批量解密、图片格式转换、图片压缩、音频和视频批量转换。尚未迁移的工具不会出现在任务中心。

任务可按状态和名称筛选。可取消的操作显示取消按钮；写入最终输出后会关闭取消入口。失败或取消的转换与流程可在当前会话重试；部分失败仍保留成功输出的位置。除下述 Word 与 PDF 解密队列外，重试会重跑整次任务，可能产生新的输出文件。任务中心重试成功后，请从任务中心打开输出，原工具页面保留原任务结果。

历史保存任务描述、状态、时间和输出路径；新版 Word 任务还保存最多 20 个源路径、ZIP 来源、源文件与结果 SHA-256 及非秘密转换设置。不保存文件内容、AI 密钥、密码或水印内容。保留最近 100 条已结束记录，运行中任务不被清除。应用重启后，未结束任务标为“已中断”，不会自动续跑。本机存储失败时显示提示，当前记录可能无法跨重启保留。清除已结束记录只删除元数据，不删除源文件或 PDF。原生批量转换依次排队，取消等待中的任务不会影响正在运行的任务。

桌面 Word 记录可点击“恢复到 Word 队列”，只读核对源文件和 PDF。保留可用结果，默认只补齐未完成或丢失项；转换前再次校验源指纹。源文件变化时点击“使用当前版本”明确接受；ZIP 变化须移除后重新添加。缺失源文件仍可查看现有 PDF，但无法从历史重新下载或重建原件。“重新生成全部”先将队列设为待转换，再由用户点击开始；使用当前输出目录另存新结果，原 PDF 不覆盖。水印和加密开关会恢复，内容与密码必须重新输入，或明确关闭该选项。旧记录未保存源信息，只能定位原结果或重新添加文件。其他工具重启后仍需重新选择文件。详见 [Word 恢复说明](../toolknit-desktop/docs/WORD_TO_PDF.zh-CN.md)。

PDF 批量解密单独管理串行队列，每批最多 50 个文件。停止操作等待当前文件完成，再跳过后续文件；成功输出仍可定位。与上述整批重试不同，解密重试只恢复失败或取消项，重新打开密码页；密码不进入历史，必须重新输入。工具内重试会同步当前队列；从任务中心恢复已关闭队列时，仅载入待重试文件。重启应用后需重新选择文件。

## 工具串联与预设

第一版提供两条固定流程：

1. 图片转 PDF → 可选连续页码 → 输出 PDF。
2. 多份 PDF 合并 → 可选连续页码 → 输出 PDF。

可调整图片质量、是否添加页码、页码起始值，用文件旁的上下按钮调整顺序。支持保存和删除最多 30 条自定义参数预设；预设不保存输入文件。

每次最多 100 个文件、150 MB 总输入、200 页，最终输出不超过 150 MB。图片复用现有本地图片读取能力，透明区域以白色填充，动态图片使用首帧；PDF 保留原有页面尺寸与顺序。最后阶段统一输出，中途取消不生成最终文件。桌面版结果保存在配置输出目录的 `Workflows` 子目录；浏览器版下载 PDF。

可以离开工作台查看其他工具，流程继续运行；在任务中心查看状态。关闭应用会中断任务。

## 验证

在 `toolknit-desktop` 目录运行：

```powershell
npm run test:productivity
npm run test:batch-rename-native
npm run build
npm run test:productivity-browser
```

浏览器测试使用 Playwright 和 Microsoft Edge。可通过 `TOOLKNIT_TEST_MODULES` 指定已有 Playwright 模块目录，或通过 `TOOLKNIT_TEST_BROWSER` 指定 Chromium 可执行文件。截图与导出样例写入 `tmp/productivity-browser`。
