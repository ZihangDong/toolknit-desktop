# 文档与自动化工作台（V3.4 开发版）

新增五项桌面入口：全局快捷启动器、文档内容搜索、文档对比、字幕工作台、文件夹自动处理。首页“新功能”或搜索工具名称即可打开；字幕位于文本分类，其余位于清理工具分类。尚未发布安装包。

## 快捷启动器

应用运行时，默认按 `Ctrl+Shift+Space` 呼出主窗口和工具搜索，应用内按 `Ctrl+K` 也可以。启动器中搜索工具名称、描述或 ID，使用上下键选择、Enter 打开、Esc 返回。展开“系统快捷键”可以修改或关闭系统快捷键；冲突会提示。

粘贴文件名或路径会根据扩展名推荐工具。打开后仍需选择实际文件，不会自动读取粘贴路径。支持最近使用记录。浏览器预览只支持应用内快捷键。

## 文档内容搜索

选择文件夹或添加文档，建立本机文字索引；输入至少 2 个字符搜索。支持 PDF、DOCX、TXT、Markdown、CSV、TSV、JSON 和 HTML。结果显示文件名、所在路径和命中文字片段，可在资源管理器定位。

首次读取后保留索引，重新索引时未变更文件复用结果、变更文件重新提取。完整无错误扫描时清除已不在目录中的旧记录；读取失败文件会移除旧文字，避免返回过期内容。清除索引不会删除原文件。

每次最多 2000 份文档、20000 个目录项、16 层目录；单文件最多 64 MB、PDF 最多 300 页，一次读取预算 512 MB。每份文档索引前 20 万字符，最多 5000 份文档。跳过链接、隐藏目录和常见依赖目录。扫描件需先 OCR。索引为应用数据目录中的本机明文数据库；浏览器预览仅保留当前会话所选文件。修改文件后需要重新索引。

## 文档对比

导入 PDF、DOCX 或文本，或直接在左右输入框粘贴文字。点击开始对比，按行显示新增与删除，支持忽略空白、仅显示变化、跳转前后变化和导出差异报告。

比较的是文字内容，不是页面视觉、图片或版式。每份最多 10000 行、100 万字符。差异计算在工作线程中执行；超大修改范围会明确标为整块替换，避免卡住界面。

## 字幕工作台

可导入 SRT/VTT 或选择音视频进行本地转写。转写复用现有 FFmpeg、Whisper 和按需安装的模型，不需要 AI Key。修改选中字幕的开始、结束时间和文字；可新增、删除、整体偏移或在播放位置拆分。

时间格式为 `00:00:00,000`，偏移单位为毫秒。正数延后，负数提前，不能产生负时间。时间无效、文字为空或包含空白分段会阻止导出，字幕重叠会提示。最多 5000 条，列表分页显示。

选择音视频后可预览当前字幕及逐句播放。预览读取上限 64 MB，编码须受浏览器支持；预览失败仍可使用本地转写。草稿自动保存在本机，导入新字幕会替换当前草稿。桌面导出到 `Subtitles` 子目录，浏览器下载 SRT/VTT。首版不提供翻译、视频烧录或多轨字幕。

## 文件夹自动处理

仅桌面版可用，应用运行或驻留托盘时每 3 秒检查一次。选择已存在、互不包含的输入和输出文件夹，设置规则：

- 图片格式转换：PNG、JPG、WEBP。
- 图片压缩：高、均衡、较小文件，复用现有无损／有损策略。
- 按扩展名复制归档：复制到输出目录中的 `pdf`、`jpg`、`txt` 等子目录。

启用或修改规则时，已有文件建立基线并跳过，之后新建或变更的文件在大小和修改时间连续两次检查稳定后处理。原文件保留，已有输出不被覆盖，下载临时文件、零字节文件和链接跳过。每条只监控第一层，最多 5000 个目录项、单文件 200 MB、最多 8 条规则。

暂停停止后续任务，已开始的文件会完成。重新启用会建立新基线。退出应用停止检查，重启后恢复已启用规则。失败记录可手动重试；转换繁忙时等待。完成指纹与规则、历史均保存在本机；若无法保存完成记录，会暂停规则以避免重复处理。

规则页显示最近 100 条处理记录，数据库保留最近 500 条；任务中心同时接收当前会话处理事件。离线目录或超过数量限制会在规则旁提示。

## 验证命令

在内层 `toolknit-desktop` 目录运行：

```powershell
npm run test:workbench
npm run test:workbench-native
npm run test:workbench-native-acceptance
npm run build
npm run test:workbench-browser
```

浏览器测试使用 Playwright 和 Edge，可通过 `TOOLKNIT_TEST_MODULES` 指向已有 Playwright 模块目录、`TOOLKNIT_TEST_BROWSER` 指向 Chromium。截图和真实导出样例写入 `tmp/workbench-browser`。
