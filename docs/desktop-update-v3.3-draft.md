# ToolKnit Desktop 3.3.0

发布说明草稿。当前尚未发布；日期、下载附件和正式提交在发布时确认。

## 主要更新

- **文件快速搜索**：新增本机搜索工作台与桌面胶囊。支持中文、拼音、后缀筛选和排序，一键在资源管理器中定位文件。首次引导后自动配置范围和可用的 NTFS 加速；完全退出后停止索引。
- **Word 转 PDF**：支持 DOC、DOCX 单个及批量转换。支持取消、重试，完成后可打开所在文件夹或导入 PDF 编辑器。
- **本地 OCR**：截图提字和扫描 PDF 共用 PP-OCRv5 模型。首次下载后可离线识别；截图翻译使用本地 OCR 与本地翻译，无需 AI Key。
- **PDF 转 Word**：支持扫描件，改善文字位置、字体、表格和常见数学符号的恢复。复杂示意图保留为图片，周围正文可编辑。多页可全部处理或选页，完成后进入共用编辑工作台并导出 Word。
- **PDF 性能与导出**：改善大文件缩略图和切页响应。修复删页、合并、拆分及独立页 ZIP 导出失败；编辑器按勾选页面导出。
- **截图体验**：预热隐藏界面，减少重复绘制、取色和整屏复制。Esc 直接退出截图，完善超时、快速重开与取消恢复；截图时保留主窗口。
- **界面与文件定位**：修复结果定位、快捷键冲突及辅助窗口状态问题。新增按版本展示的更新说明，完善双主题、支持作者页和网页工具入口。
- **下载与许可**：离线依赖统一由七彩云按需下载并校验。FFmpeg 使用带对应源码与构建材料的固定版本。当前作者自有桌面端、PDF 转 Word 引擎及 CLI/MCP 统一采用 MIT。

## 下载与使用

- 桌面端：75 项工具、12 个分类。Windows 10 / 11 x64；缺少 WebView2 时需联网安装运行时。
- 正式安装包拟用名：`toolknit-desktop_3.3.0_x64-setup.exe`，配套 SHA-256 校验文件。签名状态以最终产物记录为准。
- CLI / MCP 开发源码为 3.3.0、78 项能力。npm 当前正式版仍为 3.2.0；源码推送和桌面打包不代表 npm 已更新。
- 原文件默认保留，结果另存。复杂公式、手写、竖排或模糊扫描仍需核对，部分内容保留图片。
- 文件处理优先在本机完成。主动使用 AI 工具时，所选内容发送至用户配置的模型服务。
- 网页端适合快速打开和轻量处理，桌面端提供本地文件、系统集成及离线能力：[ToolKnit 网页端](https://toolknit.com/) · [桌面端下载](https://toolknit.com/exe.html)。
