# ToolKnit Desktop 3.3.0

发布候选说明，尚未公开。正式日期和附件在发布时确认。

## V3.3 正式版记录（待公开）

- 12 个分类、75 项工具。新增文件快速搜索、Word 转 PDF，增强本地 OCR 和扫描 PDF 转 Word。
- **文件快速搜索**：支持中文、拼音、后缀筛选、排序和资源管理器定位。主窗口与桌面胶囊互斥使用。图片支持本地缩略图和 SVG 静态预览；加载更多及刷新保留位置。完全退出后停止索引。
- **Word 转 PDF**：DOC / DOCX 支持单个和批量转换。可取消、重试，完成后可导入 PDF 编辑器。
- **本地 OCR 与翻译**：截图提字和扫描 PDF 共用 PP-OCRv5。首次下载后可离线识别；截图翻译使用本地 OCR 和本地翻译，无需 AI Key。
- **PDF 转 Word**：改善文字、字体、位置、表格和常见数学符号。复杂示意图保留图片，周围正文可编辑。多页支持选页，结果可继续编辑并导出 Word。
- **PDF 编辑与拆分**：改善大文件切页和缩略图响应。修复删页、合并、拆分 ZIP 导出失败；编辑器按勾选页面导出。
- **截图与记录模式**：减少唤起等待和重复绘制，修复 Esc 后遮罩残留及快速重开冲突。截图时保留主窗口。快捷键冲突不再阻止记录模式开启。
- **界面与稳定性**：修复文件定位、状态闪烁、双主题及窗口恢复问题。完善首次版本说明、网页入口和支持作者页。
- **依赖与许可**：运行库和离线模型由七彩云按需分发并校验。FFmpeg 更新为可追溯构建。当前作者自有代码统一采用 MIT，包含 PDF 转 Word 引擎和 CLI/MCP。

## 下载与使用

- 安装包：`toolknit-desktop_3.3.0_x64-setup.exe`，配套 `.sha256`。当前候选包未进行 Authenticode 签名。
- 系统：Windows 10 1803（内部版本 17134）及以上的 x64 系统，包括 Windows 11。缺少 WebView2 时需联网安装。
- **CLI / MCP 源码扩展至 78 项能力**，新增 Word 转 PDF。**npm CLI / MCP 3.2.0 已于 2026-10-24 发布**，当前 registry latest 仍为 3.2.0；3.3.0 归档已准备，尚未发布。[当前 npm 包](https://www.npmjs.com/package/@toolknit/cli/v/3.2.0)。
- 原文件默认保留，结果另存。复杂公式、手写、竖排或模糊扫描仍需核对，部分内容保留图片。
- 文件处理优先在本机完成。主动使用 AI 工具时，所选内容发送到用户配置的模型服务。
- [网页端](https://toolknit.com/)适合快速打开和轻量处理；[桌面端](https://toolknit.com/exe.html)提供本地文件、系统集成及离线能力。
